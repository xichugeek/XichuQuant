# 常见问题

**一定要买美国云服务器吗？** 本地 Windows 优先。服务器位置不能替代身份、行情和风险校验；本项目不要求购买特定供应商。

**浏览器关闭了后台还能运行吗？** 服务和用户自己的 Gateway 会话仍在运行时可以继续。电脑关机、休眠、会话失效和网络故障会中断依赖；网站可访问不代表券商已连接。

**系统替我登录 IBKR 吗？** 不替用户登录，也不收集券商密码或 MFA。用户在官方客户端登录，Connector 连接已授权 API。

**100 万美元账户就是模拟账户吗？** 不能仅以余额判断。必须核实 Paper 身份、客户端模式、返回账户与白名单。

**为什么有策略或订单被拒绝？** 看完整门禁/审计：未知行情、未核实年度账本、Stop、风险预算、审批、身份或配置均可能拒绝。没有低买高卖或临时 Override 的通用豁免。

**可以真实自动交易吗？** Live 下单、改单、撤单永久禁用。IBKR Paper 仍需要独立明确授权及现有审批/二次确认；内部模拟不需要连接券商。

**为什么现在说开源交付仍不能发布？** 新仓库使用独立历史；许可证与原创权属尚待批准，Linux 运行与公共 Demo 验收尚有缺口。本地代码通过不解除发布门禁。

**可以在 Linux 上直接 pnpm dev 吗？** 当前 quant-engine 的 workspace 命令是 Windows 虚拟环境路径。Linux 用户使用 Docker 指南；不要把 YAML 可解析当作实际运行证据。

**Demo 能证明策略赚钱吗？** 不能。Demo 用 SYNTHETIC 数据；历史回测、样本外、内部 Paper 和外部券商执行必须分别解释。

**需要重置数据库解决错误吗？** 不需要。先检查明确目标、配置、迁移、日志与备份；拒绝自动 reset 或覆盖真实数据。
